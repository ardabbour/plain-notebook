تبدأ كل صفحة بملف Markdown. اكتب في أي محرر نصوص، وأضف الملف إلى مجلد المحتوى، ثم ابنِ الموقع. تتشكل قائمة الصفحات ومسار التنقل وفهرس الصفحة تلقائيًا.

## ابدأ صفحة

أنشئ ملفًا باسم `content/ar/notebook/first-note.md`:

```markdown
---
title: ملاحظتي الأولى
translationKey: first-note
description: شيء يستحق التذكر.
order: 30
---
فكرة، مكتوبة.

## بعض التفاصيل

اتبع الفكرة حيث تأخذك.
```

العنوان هو عنوان الصفحة، ويحدد `order` ترتيبها في القائمة. لتنظيم الصفحات، أنشئ مجلدًا يحتوي على ملف `index.md`. أضف `draft: true` لاستبعاد مسودة من الموقع المنشور.

## صِل أفكارك

استخدم **النص العريض** للتأكيد، و*المائل* للتنويع، و[الروابط العادية](../about.md) للوصول إلى صفحة أخرى.

```markdown
[نبذة عني](../about.md)
```

تتحول الروابط النسبية إلى ملفات `.md` إلى روابط صفحات عند البناء. يؤدي الرابط إلى صفحة مفقودة إلى إيقاف البناء لتتمكن من إصلاحه قبل النشر.

## قوائم وخطط صغيرة

- يمكن للدفتر أن يحتفظ بفكرة لم تكتمل.
- قد تكون القائمة صفحة مفيدة بحد ذاتها.
  - ويمكن أن تتفرع الأفكار أيضًا.

- [x] إنشاء مكان للكتابة.
- [x] إضافة الصفحة الأولى.
- [ ] اكتشاف ما يأتي بعد ذلك.

تعكس قائمة المهام ما كتبته في الملف. عدّل المصدر لتغيير حالة المهمة.

## بعض التنظيم

| العنصر | استخدامه |
| --- | --- |
| عنوان | جزء جديد من الفكرة |
| قائمة | أشياء مترابطة |
| جدول | مقارنة سهلة القراءة |
| حاشية | تفصيل إضافي[^detail] |

[^detail]: تترك الحاشية الفكرة الأساسية تتدفق، مع مساحة لتفصيل إضافي.

::: note تذكير صغير
لا تحتاج الصفحة إلى كل الإمكانيات. ابدأ بالكلمات، ثم أضف ما يساعد.
:::

اكتب الملاحظات باستخدام `::: note` أو `::: tip` أو `::: warning`، ثم عنوان اختياري، والمحتوى، وأخيرًا `:::`.

::: details ماذا عن الأقسام القابلة للتوسيع؟
تستخدم هذه الأقسام عنصر HTML أصليًا. تعمل بلوحة المفاتيح ودون JavaScript.

اكتب `::: details` ثم العنوان، وأضف النص في الأسطر التالية، وأغلق القسم بسطر `:::`.
:::

## الشيفرة والصور

أضف اسم اللغة بعد علامات الاقتباس الخلفية الثلاث لتلوين الشيفرة أثناء البناء. تبقى الشيفرة من اليسار إلى اليمين داخل الصفحة العربية.

```js
const notebook = {
  title: 'مساحة للتفكير',
  pages: ['بداية', 'فكرة أخرى'],
};
```

ضع الصور في `public/images/`، ثم اربطها بنص بديل يصف ما يهم فيها:

```markdown
![وصف واضح للصورة](/images/your-photo.jpg)
```

حافظ على حجم مناسب للصور. يُنسخ كل ما في `public/` إلى الموقع المنشور. يظهر HTML الخام كنص؛ استخدم إمكانيات Markdown المدعومة للتنسيق.

## لغة أخرى

أضف ترجمة تحت `content/en/` باستخدام **القيمة نفسها لـ `translationKey`**. يمكن أن يختلف اسم الملف والعنوان. تربط قائمة اللغات الصفحتين تلقائيًا.

إذا لم توجد ترجمة، توضح القائمة ذلك وتقدم رابطًا إلى الصفحة الرئيسية بتلك اللغة. لإضافة لغة جديدة، أضف بياناتها واتجاه القراءة وترجمة واجهتها في `site.config.js`.

## اجعله خاصًا بك

غيّر اسمك ووصفك ولغاتك في `site.config.js`، واستبدل الصفحات التجريبية، ثم شغّل:

```sh
npm install
npm run dev
npm run build
```

ستجد الموقع الجاهز في `dist/`. يمكن نشره على استضافة ملفات ثابتة. يحتوي ملف README على تفاصيل الإعداد والنشر.
